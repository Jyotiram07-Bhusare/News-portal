# बॅकअप: "आम्हाला फॉलो करा" (Follow Us) विजेट

२४ ऑक्टोबर २०२६ रोजी हे विजेट वेबसाइटवरून काढले. त्याचा पूर्ण कोड इथे जसाच्या तसा ठेवला आहे, म्हणजे हवे तेव्हा परत लावता येईल.
हा फोल्डर `frontend/` च्या बाहेर आहे, त्यामुळे तो वेबसाइटवर प्रकाशित होत नाही (Amplify व Vercel फक्त `frontend/` प्रकाशित करतात).

**विजेट कसे होते:** डेस्कटॉपवर उजव्या कॉलममध्ये "यादृच्छिक बातम्या" च्या खाली चार रंगीत बटणे — Facebook, X, YouTube, WhatsApp. फोन / टॅब्लेटवर ते *Labels* च्या ठीक खाली यायचे, ब्रँड-रंगाच्या मोठ्या कार्ड्ससह ("फॉलो करा / सबस्क्राईब / जॉईन करा").
बटणांना खऱ्या लिंक्स नव्हत्या (`javascript:void(0)`; क्लिक केल्यावर फक्त एक छोटा संदेश). परत लावताना `href` मध्ये लोकमंगलच्या खऱ्या पानांच्या लिंक्स टाका.

## फाइल्स व त्या परत कुठे जातात

| या फोल्डरमधील फाइल | परत कुठे | किती ठिकाणी |
|---|---|---|
| `widget.html` | `frontend/index.html` — `<aside id="sidebar-wrapper">` मध्ये, `#widget-random` व `#widget-videos` च्या मध्ये | १ |
| `style.css` | `frontend/css/style.css` | ३ |
| `responsive.css` | `frontend/css/responsive.css` | ३ |
| `app.js` | `frontend/js/app.js` — फंक्शन व त्याचा कॉल | २ |
| `i18n.js` | `frontend/js/i18n.js` — `["विभाग", "Sections", ["Labels"]],` नंतर | १ |

प्रत्येक फाइलच्या सुरुवातीला व प्रत्येक तुकड्यावर तो नेमका कुठे जातो ते लिहिले आहे.
लेखाखालील "शेअर करा" पट्टी `.social-icon-box` (fb / tw / wa / cp) वापरते — ते नियम `style.css` मध्ये तसेच ठेवले आहेत; इथे फक्त Follow Us चे स्वतःचे नियम आहेत (YouTube चा रंग `.yt` सह).

मुख्य `README.md` मधील "४. मोबाईल अनुभव" यादीत विजेटची ही ओळ होती (परत लावल्यावर ती तिथे परत टाका):

```markdown
- **Follow Us**: फोन/टॅब्लेटवर *Labels* च्या ठीक खाली येते — ब्रँड-रंगाची आयकॉन कार्ड्स (Facebook, X, YouTube, WhatsApp) व "फॉलो करा / सबस्क्राईब / जॉईन करा" ओळ. डेस्कटॉपवर ते पूर्वीसारखे उजव्या कॉलममध्येच राहते. (हे `frontend/js/app.js` मधील `initFollowPlacement()` करते; ब्रँड रंग `frontend/css/responsive.css` मधील "E2. FOLLOW US WIDGET" विभागात.)
```

## परत लावल्यावर तपासा

- डेस्कटॉप: उजव्या कॉलममध्ये यादृच्छिक बातम्या → आम्हाला फॉलो करा → निवडक व्हिडिओ.
- फोन / टॅब्लेट (९८०px पर्यंत): विजेट *Labels* च्या ठीक खाली, ब्रँड-रंगाची कार्ड्स; टॅब्लेटवर चारही एका ओळीत.
- English निवडल्यावर "Follow Us" दिसते.
