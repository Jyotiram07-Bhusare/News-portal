# लोकमंगल न्यूज पोर्टल (Lokmangal News Portal)

महाराष्ट्रातील जनतेचा आवाज बुलंद करणारे आधुनिक, वेगवान आणि संपूर्ण रिस्पॉन्सिव्ह डिजिटल न्यूज पोर्टल.

---

## 🌟 वैशिष्ट्ये (Key Features)

### १. हेडर व नेव्हिगेशन (Header & Navigation)
- **Home (होम)**: सर्वात वर **प्रमुख बातमी (Lead Story)**; त्याखाली **ताज्या बातम्या (News)** विभाग (सर्व / सामाजिक / राजकीय फिल्टरसह). साप्ताहिक अंक व त्यांचे PDF **Weekly publication** विभागात.
- **Weekly publication (साप्ताहिक आवृत्ती)**: स्वतंत्र विभाग — नवीनतम अंकाचे मोठे कार्ड + **सर्व ४२ अंक**, प्रत्येकाला PDF (ऑनलाईन वाचा / डाउनलोड). अंक क्रमांक किंवा विषयाने शोध ("२५" आणि "25" दोन्ही चालतात).
- **News (बातम्या)**: खालील २ उपविभागांसह ड्रॉपडाऊन मेनू:
  - **Samajik (सामाजिक)**: ग्रामीण व नागरी समाजकारण, महिला सक्षमीकरण, पाणीपुरवठा व विकासकामे.
  - **Rajkiy (राजकीय)**: विधानसभेच्या घडामोडी, पक्षीय विश्लेषण, मंत्रिमंडळ निर्णय व निवडणुका.
- **Blogs (ब्लॉग्स)**: सुप्रसिद्ध स्तंभलेखक आणि विचारवंतांचे वैचारिक लेख.

### २. डिझाइन आणि अलाईनमेंट (Design & Alignment Reference: Xapify)
- **Xapify Templateify स्टँडर्ड**:
  - कंटेनर अलाईनमेंट (1200px ग्रिड व मोबाईल रिस्पॉन्सिव्ह)
  - लोगोवर **Shimmer Shine** अ‍ॅनिमेशन
  - **टॉपबार (Top Bar)**: थेट दिनांक, मराठी वार, तापमान व सोशल मीडिया लिंक्स
  - **ब्रेकिंग न्यूज टिकर (Breaking News Ticker)**: लाल पल्सर बॅज व ऑटो-रोटेटिंग मथळे
  - **हिरो सेक्शन (Hero Featured Grid)**: मोठ्या कव्हर कार्डसह बाजूला २ हायलाईट कार्ड्स
  - **डार्क / लाईट मोड (Dark & Light Mode)**: एका क्लिकवर स्मूथ थीम स्विच (लोकल स्टोरेजमध्ये सेव्ह राहते)
  - **सर्च बार (Search Overlay)**: सर्व बातम्यांमध्ये झटपट शोध घेण्याची सुविधा

### ३. परस्परसंवादी कार्यक्षमता (Interactive Features)
- **Article Reader Modal**: कोणत्याही बातमीवर क्लिक केल्यावर पूर्ण बातमी, ऑडिओ वाचक (Text-To-Speech Marathi), फॉन्ट लहान/मोठा करण्याची सुविधा, प्रिंट आणि WhatsApp शेअर.
- **PDF ई-पेपर रीडर**: अंकाचा खरा PDF थेट साईटवरच पान-दर-पान वाचता येतो (pdf.js; ती लायब्ररी फक्त PDF उघडला तेव्हाच डाउनलोड होते). "पान १ / २" निर्देशक, डाउनलोड व नवीन टॅब बटणे; PDF उपलब्ध नसल्यास किंवा लोड न झाल्यास स्पष्ट संदेश + पर्यायी लिंक्स.
- **दैनिक कौल (Daily Poll Widget)**: वाचकांसाठी थेट मत नोंदणी व निकाल.
- **सर्वाधिक वाचलेल्या बातम्या (Popular Posts Widget)**: क्रमांक १ ते ५ रँकिंगसह.

### ३अ. पत्ते (URLs), Back बटण व साप्ताहिक PDF
प्रत्येक पानाचा स्वतःचा पत्ता आहे, त्यामुळे ब्राउझरचे **Back / Forward**, रिफ्रेश आणि शेअर केलेल्या लिंक्स नेमक्या त्याच पानावर नेतात:

| पत्ता | कोणते पान |
|---|---|
| (काहीही नाही) | Home — प्रमुख बातमी + बातम्या |
| `#weekly` | Weekly publication — सर्व अंक |
| `#issue-42` | एका अंकाचे पान (PDF कार्ड, मागील/पुढील अंक) |
| `#cat-rajkiy` · `#cat-samajik` · `#cat-blogs` · `#cat-review` | विभाग |
| `#post-12` | एक बातमी / ब्लॉग / रिव्ह्यू |

- Back बटण: लेखावरून Back केल्यास तुम्ही ज्या यादीतून आलात तिथेच, **त्याच स्क्रोल जागी** परत येता.
- ब्रेडक्रंब (Home › साप्ताहिक आवृत्ती › अंक ४२) चा प्रत्येक भाग क्लिक करता येतो; पानाच्या शेवटी "…विभागाकडे परत" व "होम" बटणे आहेत.
- जुनी `#post-3` सारखी लिंक आपोआप `#issue-42` मध्ये बदलते; चुकीचा पत्ता Home ला जातो.

**PDF फाईल्स:** `assets/pdf/lokmangal-weekly-<अंक क्रमांक>.pdf` (उदा. `lokmangal-weekly-42.pdf`).
सध्या ४२ ही सर्व फाईल्स **नमुना (sample) PDF** आहेत — खरा अंक त्याच नावाने त्या जागी ठेवला की साईटवर आपोआप तोच दिसेल/डाउनलोड होईल. (फाईल्स दुसरीकडे ठेवायच्या असतील तर खाली "३ब" पहा.) एखाद्या अंकाला वेगळा पत्ता हवा असेल तर `js/app.js` मध्ये त्या अंकाच्या नोंदीत `pdf: "assets/pdf/…"` जोडा.
नवीन अंक जोडताना `articlesData` मध्ये `category: "weekly"` आणि शीर्षकात "अंक ४३" असे लिहा — Weekly publication विभागात आपोआप तोच "नवीनतम अंक" होतो; Labels मधील आकडे डेटावरून आपोआप मोजले जातात.

### ३ब. मोठे PDF (१०–३० MB) — साठवण व वाचन

**रीडर कसा वागतो (१०.७ MB / १२ पानांच्या चाचणी-अंकावर मोजलेले):**
- फक्त लागणारा भाग उतरतो (HTTP Range): पान १ साठी सुमारे **१ MB**; पूर्ण १०.७ MB फाईल पार्श्वभूमीत उतरत नाही. वाचकाच्या जवळची पुढची २ पाने आधीच काढली जातात (एकूण ~२.७ MB), त्यानंतर डाउनलोड थांबतो.
- पहिले पान: Slow 4G (१.६ Mbps) वर ~८ सेकंद, चांगल्या 4G (९ Mbps) वर ~२.४ सेकंद. (जुनी पद्धत: पार्श्वभूमीत ~७ MB अनावश्यक उतरत होते.)
- लोड होताना **प्रोग्रेस बार** ("३.१ MB / १०.७ MB"); न दिसलेली पाने शिमर + "पान ३" असे दिसतात; रीडर बंद केल्यावर डाउनलोड लगेच थांबतो.
- **झूम** १००% → १५०% → २००% → ३००% (`+` / `−` बटणे किंवा कीबोर्डवर `+` `-` `0`): पान नव्याने **स्पष्ट** काढले जाते (ताणले जात नाही), वाचन-जागा तशीच राहते, बाजूला सरकवता येते.
- ३६ पानांचा १७ MB अंकही चालतो: दूरची पाने मेमरीतून काढली जातात (एकावेळी ३–४ पाने), त्यामुळे जुन्या फोनवर अडकत नाही.
- डाउनलोड बटणावर फाईलचा आकार ("PDF डाउनलोड • १०.७ MB") दिसतो; फाईल अजून ठेवली नसेल तर बटणांऐवजी "PDF लवकरच उपलब्ध होईल".
- चूक झाल्यास स्पष्ट संदेश: फाईल नाही / PDF नाही / इंटरनेट नाही → "पुन्हा प्रयत्न करा" + "नवीन टॅबमध्ये उघडा" + "डाउनलोड".

**फाईल्स कुठे ठेवायच्या:** `js/app.js` च्या सुरुवातीला `PDF_BASE` आहे. तेच एक सेटिंग.

| पर्याय | कधी | लक्षात ठेवा |
|---|---|---|
| `assets/pdf/` (साईटच्या आत, सध्याचे) | काही फाईल्स / चाचणी | ४२ अंक × १० MB ≈ **४२० MB** होतात. GitHub repo शक्यतो १ GB खाली ठेवायला सांगते (५ GB खाली "strongly"); एक फाईल १०० MB पेक्षा मोठी चालत नाही; आणि PDF बदलली की जुनी आवृत्ती Git इतिहासात **कायम** राहते, म्हणजे repo फुगत जातो. Vercel Hobby चे CLI-अपलोड मर्यादा १०० MB आहे. |
| **स्टोरेज बकेट (शिफारस)** — Cloudflare R2 / Vercel Blob / Amazon S3 | रोजचा वापर, सर्व ४२+ अंक | साईट हलकी राहते, PDF बदलणे म्हणजे फक्त फाईल अपलोड (साईट पुन्हा deploy नको). R2 मध्ये १० GB स्टोरेज मोफत व डेटा-ट्रान्सफर (egress) मोफत आहे (दर कधीही बदलू शकतात — Cloudflare ची किंमत-पाने तपासा). |

बकेट वापरताना: (१) फाईल्स त्याच नावांनी (`lokmangal-weekly-42.pdf` …) अपलोड करा, (२) बकेटला स्वतःचा पत्ता द्या (R2 चा `r2.dev` पत्ता फक्त चाचणीसाठी; प्रत्यक्षासाठी स्वतःचे डोमेन, उदा. `pdf.lokmangal.com`), (३) खालील **CORS** लावा, (४) `js/app.js` मध्ये बदला:
```js
const PDF_BASE = "https://pdf.lokmangal.com/weekly/";   // शेवटी "/" असू द्या
```
CORS (R2: Bucket → Settings → CORS policy):
```json
[
  {
    "AllowedOrigins": ["https://तुमची-साईट.vercel.app", "https://तुमचे-डोमेन.com"],
    "AllowedMethods": ["GET", "HEAD"],
    "AllowedHeaders": ["Range", "Content-Type"],
    "ExposeHeaders": ["Content-Length", "Content-Range", "Accept-Ranges", "ETag"],
    "MaxAgeSeconds": 86400
  }
]
```
- `ExposeHeaders` **गरजेचे**: ते नसेल तर रीडर चालतो, पण "Range" दिसत नसल्याने पूर्ण फाईल (१०.७ MB) आधी उतरवतो. (चाचणीत मोजले.)
- CORS अजिबात नसेल तर रीडर "PDF येथे दाखवता आला नाही" + "नवीन टॅबमध्ये उघडा / डाउनलोड" दाखवतो; लिंक्स नवीन टॅबमध्ये उघडतात (साईट सुटत नाही).
- बकेट/होस्ट Range चालवतो का तपासा: `curl -I -H "Range: bytes=0-99" <PDF चा पत्ता>` → उत्तर `206 Partial Content` व `Accept-Ranges: bytes` हवे. (Vercel स्वतः हे बरोबर करते — तपासले.) Range नसेल तर पूर्ण फाईल उतरल्यावरच पान १ दिसते.
- PDF वर password/encryption नको; PDF वर `Content-Encoding` (gzip) लावू नका.

**PDF तयार करताना:** फोटो १५०–२०० dpi ला कमी करा, "Optimize for web / Fast Web View" सह एक्स्पोर्ट करा; एक अंक शक्यतो २० MB खाली. अशा PDF चे पहिले पान सर्वात लवकर दिसते.

### ४. मोबाईल अनुभव (Mobile-first)
फोनवर (२८०px ते ६००px), टॅब्लेटवर (६०१–९८०px) आणि लँडस्केपमध्ये साइट वेगळ्या, अ‍ॅपसारख्या लेआउटमध्ये दिसते. सर्व नियम `css/responsive.css` मध्ये आहेत.
- **कॅटेगरी चिप्स**: हेडर मेनू लपतो; त्याजागी बोटाने स्वाइप करता येणारी चिप्स पट्टी (होम / साप्ताहिक आवृत्ती / सामाजिक / राजकीय / ब्लॉग्स / रिव्ह्यू). निवडलेली चिप आपोआप मध्यात येते.
- **स्लाइड-आऊट मेनू (☰)**: Home, Weekly publication, News ▾ (Samajik, Rajkiy), Blogs, Reviews + शोध + Popular Items. डावीकडे स्वाइप करून किंवा बाहेर टॅप करून बंद होतो.
- **फोटो-प्रथम मुख्य बातमी**: पूर्ण रुंदीचा फोटो, मोठे मथळे, एका बोटाने पोहोचता येणारी ४४px+ बटणे; कार्ड्स स्क्रीनच्या कडेपर्यंत.
- **बॉटम-शीट पॉपअप**: ई-पेपर व व्हिडिओ खालून वर येणाऱ्या शीटमध्ये उघडतात; शीर्षक पट्टी खाली ओढून बंद करता येते.
- **Back बटण / Back-स्वाइप**: मेनू किंवा शीट उघडी असताना Back दाबल्यास ती बंद होते, साइट सुटत नाही.
- **लेख पान**: संबंधित बातम्या स्वाइप पट्टीत, शेअर बटणे २×२ ग्रिडमध्ये, कमेंट फॉर्म १६px (iPhone वर झूम होत नाही).
- **Follow Us**: फोन/टॅब्लेटवर *Labels* च्या ठीक खाली येते — ब्रँड-रंगाची आयकॉन कार्ड्स (Facebook, Twitter, YouTube, WhatsApp) व "फॉलो करा / सबस्क्राईब / जॉईन करा" ओळ. डेस्कटॉपवर ते पूर्वीसारखे उजव्या कॉलममध्येच राहते. (हे `js/app.js` मधील `initFollowPlacement()` करते; ब्रँड रंग `css/responsive.css` मधील "E2. FOLLOW US WIDGET" विभागात.)
- **नॉच / सेफ-एरिया, डार्क मोड** (ब्राउझर बारचा रंगही बदलतो), `prefers-reduced-motion` ला आदर.
- **वेग व डेटा**: लहान लोगो/जाहिरात इमेजेस (`assets/logo-192.jpg`, `assets/responsive-ad-720.jpg`), स्क्रीननुसार इमेज साइज (`srcset`), lazy-loading, फॉन्ट्स `<link>` ने समांतर लोड — पहिल्या लोडला सुमारे ७५% कमी डेटा.

> मूळ `assets/logo.jpg` व `assets/responsive-ad.jpg` फाइल्स तशाच ठेवल्या आहेत (आता वापरात नाहीत); नवीन फोटो टाकताना मोठा फोटो थेट न वापरता त्याची लहान प्रत वापरा.

## 🚀 स्थानिक सर्व्हरवर सुरू कसे करावे (How to Run Locally)

कोणत्याही टर्मिनल किंवा PowerShell मध्ये:

```bash
# Python द्वारे
python -m http.server 3000

# किंवा Node.js / npx serve द्वारे
npx serve -l 3000
```

त्यानंतर ब्राउझरमध्ये `http://localhost:3000/` उघडा.
